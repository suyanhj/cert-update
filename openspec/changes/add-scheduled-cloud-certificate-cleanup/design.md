# Design

## Context

现有调度器在每轮 `collect_all()` 后调用独立的到期检查，`ca_catalog_check` 已提供“持久化上次运行时间 + 独立周期 + 状态变化通知”的参考模式。证书部署按 provider 创建 Deployer，各平台证书库和资源绑定模型不同，现有 `get_all_product_bindings()` 会隔离子扫描错误并返回部分结果，这种容错适合展示和部署匹配，但不能用于证明证书未关联。

当前平台差异如下：

- 腾讯云使用全局 SSL 证书库，删除时可显式启用资源关联检查并轮询异步任务。
- 七牛云已有证书分页列表和删除调用，平台会拒绝删除仍绑定 CDN 或存储域名的证书，但现有列表方法会把异常转换为空列表，不能直接作为清理依据。
- 华为云 ELB、WAF、CCM 是相互独立的证书库；ELB/WAF 当前部署直接创建产品侧证书，CCM 还可保留被推送到产品的源证书。
- 阿里云 CAS 与地域化 SLB ServerCertificate 证书库不同；CAS 可通过 `ListCloudResources` 按证书 ID 查询部署产品，CLB 则需要分页盘点 HTTPS 监听器及其扩展域名引用。
- 火山引擎存在证书中心和产品侧证书，当前项目的负载均衡绑定扫描尚未完整实现。
- Cloudflare 在当前项目中只承担 DNS 能力，custom provider 没有统一证书库契约。

## Goals / Non-Goals

**Goals:**

- 用同一编排流程处理不同平台和证书库，同时保留平台特有的完整性与删除保护。
- 任何未知、部分成功或权限不足都按“可能仍在使用”处理；其中明确的权限未开通和地域不支持属于可预期能力差异，只写审计日志，不触发用户告警。
- 支持先报告、后按精确范围启用删除，并为每次判断留下不含敏感信息的审计依据。
- 最大限度复用现有 SDK 构建、配置、状态存储、调度和通知能力。

**Non-Goals:**

- 不解绑任何云资源，也不为清理目的修改 CDN、负载均衡、WAF、直播、对象存储等产品配置。
- 不删除云厂商签发、购买订单或来源无法确认的证书。
- 不根据本地文件是否存在、证书名称模式或常规绑定缓存推断云端未关联。
- 不支持 Cloudflare、custom provider 或当前项目未管理的私有证书系统。
- 不解决多进程、多实例同时运行的分布式互斥；当前应用保持单进程运行约束。

## Decisions

### 1. 清理编排与平台适配分离

新增清理服务负责调度到期判断、候选状态机、删除上限、审计和通知；平台适配器只负责一个明确证书库的严格列表、来源识别、关联查询、删除及删除后查询。适配器返回结构化结果，列表或关联查询无法证明完整时必须抛出异常，不允许用空列表表示失败。

适配器按 `provider_type + provider_name + store + scope` 唯一标识证书库。`scope` 用于表达地域、项目或企业项目等平台范围。相比把清理方法继续加入 Deployer，此方案避免部署的“尽量继续其他目标”语义泄漏到必须失败关闭的删除流程，同时仍复用现有 SDK client builder 和鉴权配置。

### 2. 配置采用双重启用和精确删除范围

顶层新增 `certificate_cleanup` 配置，核心字段为：

```yaml
certificate_cleanup:
  enabled: false
  mode: report
  interval_hours: 24
  expired_grace_days: 30
  confirm_scans: 1
  max_deletes_per_run: 20
  delete_scopes: []
```

`delete_scopes` 使用平台类型、provider 名称和证书库名称组成精确范围。即使全局 `mode=delete`，不在范围内或适配器未声明安全删除能力的证书库仍只报告。相比单一全局删除开关，双重启用可避免新增 provider 或证书库后意外获得删除权限。

### 3. 使用持久化候选状态机而不是单轮判断

新增 `data/certificate_cleanup_state.json`，通过现有 `StoreBase` 原子写入。状态包含上次到期检查时间、活动候选和最近有限数量的运行摘要；不保存 PEM、私钥、AK/SK 或完整 SDK 请求。

候选键为证书库唯一标识与证书 ID 的组合，记录证书名称、来源、到期时间、首次发现时间、最近确认时间和连续完整确认次数。只有完整扫描中的“超过保留期 + 来源允许 + 未关联”才递增确认次数；证书重新关联、来源变化、查询失败或从列表消失时重置或移除候选。默认一次完整扫描即可进入删除前实时复查；需要更保守策略时可提高 `confirm_scans`。`report` 模式的完整扫描同样累计确认次数。

### 4. 完整性以证书库为故障域

每个账号证书库先完成所有证书分页和该证书库要求的全部关联范围，再产生删除计划。任一分页、地域、项目、产品或权限失败，整个账号证书库本轮删除计划作废；其他独立账号和证书库可以继续。同一账号的多个证书库也必须逐库独立初始化，禁止因 CCM 等单库不支持当前地域而丢弃已可用的 ELB、WAF 适配器。

扫描异常分成两类：平台明确返回 403/Forbidden/NoPermission，或 SDK 明确声明服务不支持当前地域时，摘要标记为“能力不可用”，清空候选并写 WARNING 审计，但不加入通知；分页不稳定、响应损坏、网络异常、限流和未知错误仍标记为失败关闭并通知。该分类仅用于库存扫描和适配器初始化，删除阶段的权限错误仍是需要通知的真实失败。

不复用 `product_scan` 的开关或缓存来证明未关联。适配器必须执行清理契约要求的完整实时查询，或使用平台提供的权威资源关联检查。这样会增加 API 调用量，但避免把“未扫描”误认为“未绑定”。

### 5. 清理与上传部署共享账号级互斥

新增进程内账号证书操作锁注册表，键为 `provider_type + provider_name`。清理在生成最终删除计划到完成验证期间持锁；所有云证书上传及部署入口在执行云端证书操作期间使用同一把锁。

删除每张证书前仍需重新读取证书详情和关联状态，因为候选确认与实际删除之间可能发生外部变更。相比只在调度顺序上把清理放到采集之后，共享锁还能覆盖 UI 手动部署与调度任务并发的情况。

### 6. 删除契约包含平台保护和结果验证

适配器只有同时满足以下条件才能声明 `safe_delete`：

1. 能完整列出目标证书库及必要范围；
2. 能可靠识别允许自动删除的证书来源；
3. 能权威确认目标证书未关联；
4. 删除接口自身会拒绝仍在使用的证书，或支持显式开启资源检查；
5. 能在删除后通过详情或列表确认证书已不存在。

删除按照到期时间从早到晚执行，并受单轮上限约束。平台返回“仍在使用”时记为安全跳过并重置候选；鉴权、分页、限流、网络、异步任务超时或未知错误会停止该证书库后续删除。禁止在保护模式失败后退化为无关联检查的删除请求。

### 7. 平台能力分阶段落地

| 平台证书库 | 报告 | 自动删除条件 |
| --- | --- | --- |
| 腾讯 SSL | 支持 | 使用完整证书分页和证书关联资源任务；删除固定传 `IsCheckResource=true`，轮询任务并验证证书消失；缺少服务角色时整库失败关闭 |
| 七牛 Fusion SSL | 支持 | 严格分页列证书并完整扫描 CDN/存储域名关联；删除接口的 400326、400611、400911 作为平台侧在用保护 |
| 华为 ELB | 支持 | 按 project/region 分库，完整读取监听器引用；删除时仍被监听器使用的 409 作为平台侧保护 |
| 华为 WAF | 支持 | 按 project/enterprise project 分库并完整读取防护域名引用；只有官方接口行为和离线测试能证明在用保护后才声明 `safe_delete` |
| 华为 CCM | 支持 | 使用 `ListDeployedResources` 检查部署资源；只处理明确的上传证书，产品侧副本与 CCM 源证书分别审计 |
| 阿里 CAS | 支持 | 使用 `ListCloudResources(CertIds=[...])` 按证书 ID 完整查询全产品部署资源；由于 `DeleteUserCertificate` 未明确承诺在用拒绝，保持 `safe_delete=false` |
| 阿里 CLB ServerCertificate | 支持 | 完整分页扫描配置地域的负载均衡、HTTPS 监听器和扩展域名，按证书 ID 匹配；删除前重复实时扫描，并依赖 `DeleteServerCertificate` 的在用拒绝错误作为平台侧保护 |
| 火山证书中心及产品侧证书 | 支持 | 第一阶段固定为 report；当前关联扫描覆盖完整前不得启用 `safe_delete` |
| Cloudflare、custom | 不适用 | 不创建适配器，不进入清理范围 |

平台文档或 SDK 能提供删除接口，不等于该证书库具备安全删除能力。`safe_delete` 是代码中显式声明并由契约测试覆盖的能力，不根据配置动态猜测。

### 8. 调度、审计与通知复用现有设施

在现有调度循环中于采集后调用 `cleanup_if_due()`，其内部锁防止同一进程重复执行，并以状态文件中的 `last_checked_at` 判断 24 小时等独立周期。阻塞型 SDK 调用通过线程池执行，不引入新的调度框架。

每轮生成按平台、provider 和证书库分组的摘要，包括扫描数、候选数、成功删除数、有关联跳过数、达到上限未处理数、能力不可用及失败原因。复用现有钉钉、邮件、Rocket.Chat 统一通知入口；成功删除、候选变化或未知失败时通知，无变化的健康轮次以及仅有能力不可用的证书库只写审计和日志。异常文本在入库、日志和通知前移除完整 SDK `Response`、编码诊断串及现有敏感字段。

## Risks / Trade-offs

- [云平台新增产品可能产生未覆盖的证书关联] → 适配器以明确的证书库与关联范围声明能力；新增产品默认使相关平台保持 report，经过文档核对和契约测试后才能加入安全删除范围。
- [权限不足看起来像空资源列表] → 严格接口不提供空列表兜底；任何鉴权或范围发现失败使整个账号证书库删除计划失效，明确的权限未开通只记审计而不持续告警。
- [外部控制台在候选确认后建立新关联] → 账号锁防止应用内并发，删除前实时复查并依赖平台侧在用保护处理外部并发。
- [状态文件损坏导致候选历史丢失] → 复用 `StoreBase` 的损坏文件备份与原子写入；恢复为空状态后必须重新完成配置次数的连续扫描。
- [大量证书和全地域查询增加 API 调用和调度时长] → 默认每日运行、分页、复用一次扫描结果、限制删除数量，并对平台限流使用有界重试；不以降低完整性换取速度。
- [删除不可恢复] → 默认禁用、启用后默认 report、要求精确删除范围、保留期、完整候选扫描、删除前独立实时复查和平台在用保护；回滚只能停止后续删除，不能恢复已删除证书。
- [单进程锁无法覆盖多个应用副本] → 当前部署只支持单进程实例；如未来允许多副本，必须先引入分布式租约再开放自动删除。

## Migration Plan

1. 发布配置模型、状态存储、核心编排和全部 report 适配器，保持 `enabled=false`，验证现有部署行为不变。
2. 在测试账号启用 `report`，至少完成一轮完整扫描，核对候选来源、到期时间、关联结果和通知。
3. 先仅把腾讯 SSL 与七牛 Fusion SSL 的测试账号证书库加入 `delete_scopes`，验证平台拒绝在用证书、删除后复查和单轮上限。
4. 生产先为单个账号启用删除，再逐账号放开；华为各证书库只有通过各自保护验证后启用。
5. 阿里云 CAS 保持 report；阿里云 CLB 先在测试账号验证完整引用扫描和平台在用拒绝，再将单个账号的 `slb` 库加入 `delete_scopes`；火山引擎继续保持 report。
6. 回滚时将 `enabled=false` 或 `mode=report`；保留状态和审计文件，避免回滚后丢失调查依据。
