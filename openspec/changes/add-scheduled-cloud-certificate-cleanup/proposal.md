# Proposal

## Why

多云证书部署会持续在各平台证书库中留下过期证书和部署失败后未绑定的证书，长期累积可能触发平台配额，并增加证书管理成本。需要增加统一、可审计且失败时默认不删除的定时清理能力，在确认过期且未被任何云资源使用后安全释放证书。

## What Changes

- 新增跨云证书清理服务，按平台、账号、地域/项目和证书库分别枚举证书并判断过期状态。
- 新增 `report` 与 `delete` 两种运行模式；默认使用 `report`，仅报告候选证书，不执行删除。
- 自动删除仅面向平台明确标识为用户上传或本系统管理的证书副本；云厂商签发、购买订单及来源不明的证书只报告不删除。
- 仅将“超过保留期、一次完整扫描确认未关联、删除前再次实时确认”的证书纳入自动删除；平台删除接口仍必须启用在用保护。
- 关联检查、分页、地域或项目查询任一不完整时，对应账号证书库本轮不得删除任何证书；未知异常产生失败通知，明确的无权限、未开通能力或不支持地域仅记录审计日志。
- 清理与证书上传、部署互斥，防止新证书上传后尚未完成绑定时被误判为无效。
- 复用现有调度器按独立周期运行，默认每 24 小时检查一次，并保存候选状态和清理审计记录。
- 复用现有通知通道，按平台、账号和证书库汇总报告候选、成功删除、仍有关联、失败和安全跳过结果；预期的能力不可用不进入用户通知。
- 平台能力分阶段启用：腾讯云与七牛云在平台侧关联保护下支持自动删除；华为云按 ELB、WAF、CCM 分库实现并验证；阿里云 CAS 按证书 ID 查询全产品部署关系但保持仅报告，地域化 CLB 完整盘点监听器与扩展域名引用后可在平台在用保护下安全删除；火山引擎在关联信息未能完整证明前仅允许报告；Cloudflare 和 custom provider 不参与云证书库清理。

## Capabilities

### New Capabilities

- `cloud-certificate-cleanup`: 定义跨云过期证书发现、完整关联校验、候选确认、安全删除、调度、审计与通知行为。

### Modified Capabilities

无。

## Impact

- 配置模型和示例配置新增证书清理开关、模式、周期、过期保留期、连续确认次数、单轮删除上限及平台/账号范围。
- 调度服务新增独立到期检查，并与部署流程共享互斥保护。
- 新增清理编排服务、持久化候选/审计状态，以及各平台证书库适配器。
- 腾讯云、七牛云、华为云、阿里云和火山引擎 SDK/API 调用面会增加证书列表、关联校验、删除和删除结果确认能力。
- 通知汇总新增证书清理来源；通知和日志不得包含证书 PEM 或私钥。
- 需要离线单元测试覆盖分页、部分失败、权限失败、并发部署、候选确认、删除前复查、平台侧拒绝和通知汇总；真实云验证必须先使用 `report` 模式。
