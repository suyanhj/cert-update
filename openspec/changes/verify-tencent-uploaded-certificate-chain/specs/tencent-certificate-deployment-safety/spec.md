# Spec Delta

## Purpose

确保腾讯云返回的证书 ID 确实保存了本轮本地待部署的完整证书链，防止重复证书 ID 指向缺链内容并被继续下发到生产资源。

## ADDED Requirements

### Requirement: 腾讯证书上传后必须验证远端证书链
系统 SHALL 在腾讯云证书上传返回非空证书 ID 后查询该 ID 的证书详情，并比较远端与本地待部署证书链的证书数量及指纹集合。只有两端证书链完全一致时，该 ID 才可用于后续部署。

#### Scenario: 新证书链验证一致
- **WHEN** 腾讯云返回证书 ID，且该 ID 的证书详情包含与本地待部署证书链相同的全部证书指纹
- **THEN** 系统接受该证书 ID并继续 SSL Host 扫描及产品部署

#### Scenario: 重复证书 ID仍保存缺失链
- **WHEN** 腾讯云返回已有证书 ID，但该 ID 的远端证书链缺少本地已补全的证书
- **THEN** 系统使用 `Repeatable=true` 强制重传一次，并只在新返回 ID 的证书链与本地完全一致后继续该腾讯账号本轮部署

#### Scenario: 远端链包含不同证书
- **WHEN** 腾讯云返回证书 ID，但远端证书链的证书指纹集合与本地链不同
- **THEN** 系统强制重传一次；重传后仍不一致则终止该腾讯账号本轮部署

#### Scenario: 强制重传后证书链一致
- **WHEN** 首次上传返回缺链旧 ID，且使用 `Repeatable=true` 重传后的 ID 包含与本地一致的完整链
- **THEN** 系统接受重传返回的 ID，并且后续 SSL Host 扫描和产品部署只使用该已验证 ID

#### Scenario: 强制重传后仍不一致
- **WHEN** `Repeatable=true` 重传返回的 ID 仍缺链或包含不同证书
- **THEN** 系统终止该腾讯账号本轮部署，且不得继续重试上传

### Requirement: 证书详情不可验证时必须安全失败
系统 MUST 在腾讯证书详情查询失败、详情缺少公钥证书、远端 PEM 无法解析或链比对无法完成时返回明确错误，且不得使用未经验证的证书 ID调用任何腾讯云产品扫描或部署接口。

#### Scenario: 详情查询失败
- **WHEN** 上传返回证书 ID 后，腾讯证书详情接口返回异常
- **THEN** 系统记录验证失败并且不调用 SSL Host 扫描或证书部署接口

#### Scenario: 远端证书内容不可解析
- **WHEN** 证书详情返回空公钥证书或无法解析的 PEM 内容
- **THEN** 系统记录验证失败并且不调用 SSL Host 扫描或证书部署接口

### Requirement: 证书链验证日志不得泄露敏感材料
系统 SHALL 记录证书 ID、上传结果类型、请求 ID、证书数量和证书指纹等排障信息，但 MUST NOT 记录私钥或完整证书 PEM 内容。

#### Scenario: 验证成功日志
- **WHEN** 腾讯远端证书链与本地链一致
- **THEN** 日志包含证书 ID、链长度及非敏感指纹摘要，且不包含私钥和完整 PEM

#### Scenario: 验证失败日志
- **WHEN** 腾讯远端证书链与本地链不一致
- **THEN** 日志包含本地和远端链长度及指纹差异，且不包含私钥和完整 PEM
