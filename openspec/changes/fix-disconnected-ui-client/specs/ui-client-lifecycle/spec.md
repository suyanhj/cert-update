## Purpose

定义长时间证书操作与浏览器页面连接之间的行为，使页面切后台、刷新或关闭后，已授权业务仍可完成，后续页面交互只作用于存活且连接有效的客户端，避免使用已销毁页面。

## ADDED Requirements

### Requirement: 异步结果更新遵守连接状态
系统 SHALL 在异步操作后的通知、控件更新和页面刷新前检查客户端未销毁且连接有效；不满足时跳过页面交互，后台业务继续正常完成。

#### Scenario: 续签后原页面已删除
- **WHEN** 强制续签完成前原客户端已被删除
- **THEN** 保留续签结果且不向旧客户端发通知或进入其上下文

#### Scenario: 保存配置期间断开
- **WHEN** 配置应用完成或失败时页面连接已断开
- **THEN** 保留配置操作结果，不再更新旧页面控件

#### Scenario: 有效客户端正常通知
- **WHEN** 异步操作结束且客户端仍连接
- **THEN** 正常展示结果通知或控件状态
