# Spec Delta

## Purpose

定义账号失败独立汇总的可观察行为，确保运维人员能够获得明确且一致的运行结果，并通过失败条件和隔离场景验证系统可靠性，避免后台异常被静默忽略。

## ADDED Requirements

### Requirement: 账号失败独立汇总
系统 SHALL 将单账号部署器构造、上传和部署失败计入该账号结果，继续其他账号和 Nginx，并在汇总中保留成功目标。

#### Scenario: 一个账号上传失败
- **WHEN** 账号 A 上传失败且账号 B 有可部署目标
- **THEN** B 和 Nginx 继续执行，汇总保留 A 失败和 B 成功
